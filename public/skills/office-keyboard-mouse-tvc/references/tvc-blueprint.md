# 完整 TVC 方案蓝图

用于阶段一：产品素材→完整TVC方案＋对应九宫格分镜图制作规范。每部分填写当前产品的实际内容；不交付逐镜视频执行脚本或视频提示词。收到完成版九宫格后，按 [board-to-video.md](board-to-video.md) 执行后续阶段。没有足够事实的功能不能用占位参数伪装成结论。

## 八段的办公键鼠转译

| 段落与参考时间 | 叙事职责 | 可选办公表达，按事实选用 | 连接设计重点 |
| --- | --- | --- | --- |
| 01 产品建立 0–20s | 产品成为片头，建立质感与视觉母题 | 0–2s 轮廓掠光；键帽/滚轮/腕托真实微距；展示套装关系；末镜产品右置、左侧留白 | 从真实键帽边线、桌面遮挡或手部运动进入情境；无开场字幕 |
| 02 情境一 20–30s | 让主卖点首次变成用户体验 | 如确认人体工学，用一次自然落腕、输入、握鼠完成任务；否则用实际主卖点改写 | 情境由功能决定；末状态预备连接下一动作 |
| 03 情境二 30–37s | 换一种任务或空间证明辅助收益 | 如确认静音，用安静共享空间的一次输入与同伴持续专注表达；不靠虚构分贝计或静音轨证明 | 点击/落指/滚轮运动匹配；保持自然操作声 |
| 04 情境三 37–45s | 展示真实操作逻辑与效率收益 | 如确认多设备，拍实际切换控件与对应屏幕输入；否则深化其他已知功能 | 屏幕响应后期合成；不增跨屏拖拽或键鼠联动 |
| 05 情境四 45–54s | 扩展生活关联并回扣主卖点 | 如确实便携，切至移动工位；否则保留桌面，以阅读、表格或晚间收工回扣体验 | 从手部细节拉至人与桌面关系，为高潮扩景 |
| 06 高潮 54–68s | 既有场景集中回响，强化差异点 | 先用0.3–0.5s动作短切，再留可读时长给核心功能演示；不在高潮临时塞入新功能 | 运动匹配硬切；靠真实动作声密度制造高潮；结尾实物遮挡或匹配切至暗色产品 |
| 07 参数/真实生态 68–76s | 用少量事实完成理性闭合 | 已确认的续航/连接/尺寸等关键参数；真实接收器、线材或软件。无生态就用功能细节与套装整体关系 | 数字与UI后期制作，不编造内部结构/配件；保留合理阅读时间 |
| 08 品牌落版 76–82s | 回到同一视觉母题，留下产品和主题 | 与开场一致的产品朝向、右侧摆位和左侧口号；Logo使用核准素材 | 动作减速到静止；文字硬切/遮挡揭示，尾音渐弱但画面不淡出 |

这些情境是选择示例，不是产品功能预设。仅有静音与舒适两个卖点时，可以设置晨间写作、共享工位、午后表格与晚间收工，分别突出不同任务中的同一收益；不能为保留表格而捏造多设备、便携或充电。

默认 82 秒中，20 秒开场必须承载产品形态、细节和品牌记忆，不能全为慢速空镜。用户允许重分配时可缩短开场，把时长给使用证明；交付中写明调整理由及新时间码。

## 最终方案必须包含的内容

### 一、项目基本信息

日期使用实际策划日期，不照抄参考片日期。写品牌、型号、品类、影片名、片长、市场与投放假设、画幅、交付规格、模型及核实状态、制作路径、音频规则、方案版本。未知事实简明标记待确认。

### 二、核心创意与主题

写目标人群、一个具体办公需求/矛盾、产品如何改变体验、核心主题句、原创 Slogan、八段情绪路径。主题不能只是「高效舒适办公」等形容词堆叠；应能指导每段动作与取舍。

### 三、影片调性与视觉风格

明确色彩情绪闭环，产品材料如何受光、背景与桌面关系、近中远景、主光方向、人物服装与动作基调、焦点/景深和镜头运动强度。选一条可以贯穿全片的母题，如「落指的弧线」或「桌面光带」；不照搬运动相机的黑绿岩石。

### 四、产品事实与核心卖点

列产品不变特征、素材索引和卖点映射。每个 C 编号含事实依据、使用动作、用户收益、首次植入、后续强化及拟用文案。对待确认参数，给出不依赖该参数的镜头方案，避免整片卡在数字上。

### 五、完整故事大纲：八段

每段写名称、精确时间码、目标、卖点、人物/场景锚点、按发生顺序的画面、主运镜和首尾状态、声音、字幕、衔接、已有素材状态。段落之间构成同一创意推进，不用八段独立产品说明拼接。

### 六、制图用镜组与连续性意图

只规定为制图服务的叙事镜组和拟用状态，不提前锁定最终视频镜头数量或生成动作。最终镜头及提示词以用户回传的实际画面为依据。

```text
拟定镜组 / 所属段落 / 段落内建议时长：
对应卖点及依据：
拟用首态格 / 关键态格 / 尾态格：
每格静态构图、主体朝向、接触与光线：
格间关系：同一动作前后状态，或不同镜头需硬切：
与下一镜组／下一板的目标连接格及匹配元素：
允许在回传后调整的动作／时间范围：
缺失素材与制图验收点：
```

本阶段可以给九宫格图像生成提示词；不能把镜组描述包装成已绑定成图的视频提示词。

### 七、分场景九宫格确认与制作清单

每个段落给板号G01等、场景/人物锚点、产品素材、统一光线与环境条件、3×3 格位映射及九宫格英文图像提示词。每格按阅读顺序 01–09 写，不能与人物／包袋编号混淆：

```text
唯一格位地址（如G02-04） → 拟定镜组 → 建议时间位置 → 静态用途
画面：主体位置、景别、动作已经发生到哪一步、方向、接触、光线
关系：与哪一格是动作前后态，与哪一格是剪辑连接
```

若一镜组在三格中分别展示拟用首、中、尾状态，明确它们不是三次切镜。先检查规范的产品几何、人物、左右手、摆位、光线与运动方向要求，再写跨板尾首格连接清单。未看到成图不能声称实际连续性已通过。尚未生成的写「制作规范完成，待用户制图回传」，不编造生成记录。

交付完整八段的九宫格制作规范及每板图像提示词，然后说明下一步是用户回传完成版九宫格。视频脚本与视频提示词须在收到相应成图后再交付，不以旧的文字脚本代替读图。

### 八、声音与音效设计

逐段写环境底声、操作同步点、音效层级、跨场衔接与高潮密度变化。动作声音应服从真实产品与主卖点，静音产品不能在高潮突然变成机械键盘般的响亮敲击。最后允许声音尾音渐弱到静音，画面仍采用静止结束。

### 九、字幕设计规范与字幕清单

列每条实际文案、语言、对应卖点、入出点、停留时长、位置与后期方式。中文普通卖点 4–8 字；英文通常 2–5 个简短词。完整口号、准确参数和品牌名不为凑字数改错。中文较长句拆成两条短句；中文和英文为制作选项，不默认在成片同时双语堆叠。

字幕示例只能在事实支持时使用，如中文「轻声输入」「专注继续」，美区版本如「Quiet Keys」「Keep Your Focus」。不把示例当成用户产品已确认文案。

### 十、片头与终落版设计

具体写0–2秒产品如何可见、开场结束留白和运动方向，及76–82秒怎样回到同一产品朝向和构图。片尾给足口号可读时间，明确 Logo/字体来自用户资产或后期核准文件。不要把第三方参考品牌、广告口号或未经允许的促销 CTA 搬入本片。

### 十一、转场设计规范与连接清单

列七个跨段转场和段内关键连接。每项写上一镜尾态、动作/构图匹配元素、具体切点、下一镜首态、剪辑实现及必要声音桥。避免用「无缝」「高级」代替做法。

如需转黑，用黑色实物/产品遮挡满屏后硬切至暗场，或两帧暗色构图匹配硬切。不得通过画面透明度变化伪装成「能量收束」。声音可以提前/延后衔接，画面禁叠化不等于禁止声音衔接。

### 十二、制作顺序、验收与缺口

明确以下节点：用户提供产品素材 → 阶段一TVC方案与九宫格制作规范 → 用户制作并回传完成版九宫格 → 实际读图／格位映射 → 基于实际格位写视频脚本与提示词 → 需要时导出高清单格 → 图生视频 → 剪辑／字幕／UI／声音合成 → 成片验收。不为每格反复请求确认，但不得越过实际九宫格这一画面依据。

列出实拍/真实素材/后期需求、缺失角度、待核实参数和工具限制；标明脚本已检查什么、画面尚未验证什么。不附无关平台版本或强制软件生态，不声称提示词保证成片合格。
