# 办公键鼠完整 TVC 策划

## 目标与范围

把具体办公键鼠产品的资料转化为可供客户审稿、分镜制图、图生视频和后期剪辑使用的完整 TVC 方案。继承用户参考片的叙事结构与制作约束，不移植运动相机的功能、口号、人物或已有素材编号。

本技能负责完整品牌片。15–30 秒功能短片不默认扩写成 82 秒；用户明确要求本技能做短版时，压缩八段的叙事职责，不强塞四套场景。不依赖其他办公视频技能的默认时长、配乐或禁字幕设置。

交付分阶段进行，不能在第一次策划时一并产出未绑定实际九宫格的视频执行稿。只有用户另行要求制作时才调用可用的图像/视频工具，并遵守对应工具、技能与授权要求。

## 阶段路由与交接：先图后视频

以当前收到的实际素材判断阶段；本节优先于任何旧稿中的一次性交付列表。

1. **阶段一：素材→TVC方案＋九宫格制作规范。** 读取 [references/tvc-blueprint.md](references/tvc-blueprint.md)。交付完整创意、分段时间轴、场景／人物／产品锚点、声音字幕和连续性意图；为每板每格规定静态画面、用途、构图、建议动作前后状态及跨板连接，并可给九宫格图像生成提示词。此时不交付逐镜视频执行脚本、视频生成提示词或假装已经存在的首帧。镜组、时间位置和状态是制图意图，不能代替回传图像。完成这些交付后，清楚说明下一步由用户制作并回传九宫格。
2. **阶段二：完成版九宫格回传→读图与映射。** 读取 [references/board-to-video.md](references/board-to-video.md)。实际查看每张图片，以真实文件名／附件序号＋版本＋板号＋格号定位；登记每格看得见的主体、景别、朝向、手部接触、光线与画面状态。不能把规范当成实际成图描述。发现偏差时优先按真实可用画面调整动作与连接，仅将影响产品真实性或关键动作的问题列为补图项；无需让用户逐格再确认已明确为完成版的图片。
3. **阶段三：实际九宫格→逐镜视频脚本＋提示词。** 在已查看的回传板图基础上输出「视频镜头ID→源图版本／板号／格号→实际首态→动作与运镜→可达尾态→下一镜来源及剪辑点」。只有本阶段提供逐镜英文视频提示词。没有完成版九宫格时，阶段三保持待回传，不用旧的文字分镜填补。

用户只回传部分板图时，对已收到且可用的部分完成读图及视频脚本，未收到的段落标明缺图；不能假称已完成全片逐镜稿。用户修改某张板图后，保留其他已确认段落，仅更新受影响镜头、连接和时间分配。规划与实际冲突时不要求模型用变形、换手或穿透来追上旧脚本。

## 输入与开工

用户询问需要什么材料，或资料不足时，读取 [references/intake.md](references/intake.md)。最低开工资料是可识别的产品图/准确外观资料，以及按优先级排列的真实核心卖点。现有资料足够时直接起稿，不强制完整填表。

资料不足以识别产品或确定主卖点时，先给出明确的资料缺口；可以做标明假设的创意方向，不能冒称已经完成该产品的定制TVC。其余非阻塞信息使用以下默认并简述：

- 片长约 82 秒，八段结构；16:9，1920×1080 为后期交付目标。
- 目标为办公键鼠品牌主片；结合当前项目可默认 Amazon US 语境，但具体投放位置待确认，不据此声称平台审核通过。
- 中文策划和导演说明，英文模型提示词；面向 Amazon US 的成片字幕使用简洁美式英语，用户指定中文时改用中文。
- 全片仅同期音、环境声和音效，无 BGM、无旁白、无人物对白。
- 极简短字幕允许存在，交由后期制作；开场无字幕，结尾品牌口号固定停留。
- 真实办公电影摄影质感；不自动继承参考片的幽绿、悬浮岩石或失重设定。色彩围绕产品和品牌确定。
- 工具与模型未指定时采用通用图生视频执行方案。参考文档提到 Seedance 2.5 不代表本项目已经选定该模型。

仅询问会实质改变脚本真实性的缺口，合并为少量问题；其他镜头可以继续策划。用户明确选择始终优先于默认。

## 产品事实与卖点分配

先建立产品事实卡及素材索引：P01 产品、H01 人物、S01 场景、R01 已有片段、C01 卖点。引用真实文件名或「用户第几张图」，不伪造图片ID、文件路径、生成任务ID和审核状态。

区分「图片可见」「用户提供」「规格/测试资料支持」「待确认」。外观不能证明材质、静音数值、续航或连接功能；用户口述的数字可以作为待核实资料，不自动成为已获证实的广告结论。

为每个实际采用的卖点填写：事实与来源 → 对应办公动作 → 可观察的用户收益 → 首次出现与强化段落 → 字幕及依据缺口。选一个主卖点、通常 2–3 个辅助卖点；卖点少时用不同情境深化同一收益，不凑满功能清单。

办公键鼠的专属限制：

- 人体工学：展示真实曲线、腕托和自然腕部姿势；不能推导治疗疼痛、预防疾病、骨骼矫正或保证不疲劳。不用夸张痛苦前后对比代替产品证据。
- 静音：按键/点击声保留合理听感；无实测录音时标注「设计音效，非声学测试」。不把音轨归零、同事没醒或虚构分贝对比作为性能证明。
- 多设备：分别确认连接方式、可配对数量、切换控制位置和各设备支持范围。蓝牙/双模不等于跨屏拖文件、光标自由穿梭或键鼠同时切换；键盘与鼠标的功能分别核实。
- 续航：区别可更换电池、充电与续航时长。没有资料不加 USB-C、充电灯、电量百分比或「几个月免充电」。时间流逝仅作叙事，不证明参数。
- DPI 与效率：只演示已确认的按钮/软件行为；DPI 高不等于精度更高，不编造档位或效率提升百分比。
- 便携、耐用和配件：保持真实尺度、重量和支持关系；不把泼水、摔落、拆机、热插拔、键帽替换、配套软件或不存在的配件强加给产品。

## 八段结构与完整方案

策划完整方案时必须读取 [references/tvc-blueprint.md](references/tvc-blueprint.md)，按其中的交付章节写成针对实际产品的已填充方案，不只输出模板。

叙事职责固定为：产品建立 → 四个真实办公情境 → 高潮蒙太奇与主卖点强化 → 参数/实际生态 → 产品定格与品牌闭合。情境内容由真实卖点驱动，不能倒逼产品拥有四种功能。四个情境可以属于同一空间的不同时刻或任务，不必制造四位人物和四处地点。

参考节奏为 0–20 / 20–30 / 30–37 / 37–45 / 45–54 / 54–68 / 68–76 / 76–82 秒。作为对标稿保留这一节奏；若用户只要求借鉴结构、明确片长另定或开场不承载足够信息，可调整段长，并说明实际采用的版本。不得不告知就改成普通 30 秒商品视频。

先写一个具体办公洞察、主题句、原创品牌口号和一条视觉母题，再分配镜头。场景选择应让主卖点发生作用，而不是在办公室、咖啡馆等空间里重复同一个打字动作。

## 摄影、动作与剪辑约束

- 以真实材质、可信尺度和近中远景关系建立空间；微距可以选择性对焦，功能演示应保留足够景深。轻微手持、自然畸变和眩光仅在适合镜头时采用，不能把按键、Logo和接口虚化到无法验收。
- 产品开篇，拒绝传统独立 Logo 片头。0–2 秒可用背景暗、产品已可见的掠光微距，不做从全黑逐渐显影的淡入。
- 全片禁止叠化、溶解、淡入淡出。使用动作/构图匹配硬切、实物遮挡切、镜头穿越遮挡物，以及必要的明确直接切换。
- 每个剪辑连接写清「上一镜尾状态 → 切点 → 下一镜首状态」：运动方向、主体画面位置、视角/景别、速度、手部和桌面摆位、光线连续性。不同场景允许光色变化，利用动作或构图匹配解释切换。
- 连续运镜链条是可执行的剪辑连续性，不承诺整片一次生成或物理上的伪一镜到底。不为无缝强行穿透产品、手掌、桌板。
- 开场若选悬浮产品，明确为受控 CG 展示并设计可信运动；不把拆开的外壳、内部透视或爆炸图当成未经核实的真实结构。
- 每镜一个主要动作和一种主要运镜；细小手部操作用稳定的可读角度，避免高速打字叠加复杂环绕、重遮挡及光照突变。
- 结束回到开场的产品朝向、构图留白、光色或视觉母题。固定字幕可直接出现或用遮挡揭示，禁止用透明度淡入。

## 声音与字幕

声音构建节奏：键帽回弹、鼠标轻点、滚轮、实际切换键、桌面轻触、衣料、脚步、室内底噪及受控的非旋律转场音效。高潮缩短事件间隔、加强同步落点和声场对比，不能加入鼓点、节拍循环、旋律、氛围配乐或借「音效」名义放入 BGM。没有对应功能的电子反馈声不能暗示产品真的发声。

中文普通卖点字幕每次显示 4–8 个汉字，较长的「功能·收益」拆成先后短句；英文通常每次 2–5 个简短词，以实际阅读时间为准，不能套用汉字计数。参数、单位、品牌标识和片尾口号按准确性与可读性另定。每次只闭合一个意思，明确入点、出点和位置，不全程挂字、不写长解释卡。普通短字幕通常至少约 1 秒可读，较长文字延长停留；0.3–0.5 秒蒙太奇镜头不逐镜闪长句，可把一条短字幕跨数镜保留后移除。

开场无字幕。若参考稿有「鼓点」「长字幕」「浮现/转黑」等含混词，按上述声音、短句和遮挡/硬切规则具体化，优先满足用户明确约束。

## 分场景九宫格与逐镜提示词

阶段一为八段分别建立九宫格制作规范；如用户仅指定部分场景，则只细化相应段落。每格代表一个静态状态，不代表固定一秒或必须九次切镜。用独立的板号G01等与格号01–09组成唯一地址，如G02-04；道具／人物编号不得与板号混用。注明画面意图、建议时间位置及「拟用首态/动作关键态/拟用尾态/独立切镜」用途；同一镜组可占多格，但最终视频分镜必须在回传后由实际画面决定。某段超过九个关键态时拆成多板，不硬塞同板。

每格 16:9，3×3 等比例排布；无边距时整板同为16:9。实际生成受工具尺寸支持限制，给的是构图/交付要求。编号、边框和注释后期添加在画面外，不混入可用素材。

九宫格用于比较构图和连续性，也是后续视频脚本的画面来源。规范应明确每组相邻格是「同一动作的前后状态」还是「需要剪辑的不同镜头」，并把跨板尾首格直接对应起来。正式图生视频使用回传板图对应的独立高清单格；整板只作上下文参考。低清时注明需导出／补充对应高清格，不保证简单放大能恢复细节。裁切范围和已导出的文件名要如实记录，不能伪称已经裁好。

阶段三每镜交付独立可复制的英文视频提示词，明确回传源图版本、板号与格号，不能只写「同上」。先中文记录源格实际画面，再写从该状态出发的主体动作、主运镜、速度、可达尾态和几何保持条件。已有成图不再凭空重写英文首帧生图提示；只有具体格确需补图时另列对应的补图说明／图像提示词。尾格只有在已存在且工具支持时作为尾帧输入，否则作为结束状态参考，不伪称模型支持首尾帧锁定。

区分成片使用秒数与模型生成档位。未验证的模型不写确定的精确时长、多参考数量、首尾帧能力、负面提示栏或原生分辨率；设置与正文提示词分开。用户要求某模型具体设置时检查对应版本的官方资料，无法核实则保留工具中立执行说明。

锁定产品轮廓、键帽行列与字符方向、Logo、滚轮、接缝、接口及配色。没有参考的背面不凭空补造。手指保持合理解剖和遮挡，按压接触及回弹可信，握鼠时产品不变形不滑穿；不要求任意视角始终露出五根手指。精确字符、Logo和屏幕联动优先真实素材、可控三维或后期合成，不靠深度虚化掩盖错误。

## 交付前检查与修改

阶段一交付前检查分段时间轴、卖点依据、九宫格格位规范与跨板连接，不声称实际图像或逐镜动画通过。阶段三另检查：每镜都有真实源图版本与格位；首态符合该格，不要求重复已完成动作；相邻格可连续或明确安排剪辑；视频时间码无空档无重叠，时长加总一致；无BGM/旁白/禁用转场；字幕可读；产品与既有素材状态未被编造或覆盖。

报告「策划检查」与「尚未生成/实拍验证」的界限。已有生成片段才做实际画面验收，不把文字防错要求当成零穿帮保证。若用于特定 Amazon 广告位，单独核实当时官方时长、文字、音频和品牌规则；82 秒品牌主片不自动等于所有广告位可投放版本。

用户修改时仅更新受影响的镜头、连接、卖点映射、时间码和提示词；锁定已确认内容，未经用户要求不改其他段落。实际制作同一镜头连续两轮仍失败时，重新判断原因，改用更稳定角度、重建关键帧、实拍或合成，不无限重复同一提示。
